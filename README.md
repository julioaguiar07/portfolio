# Portfólio — Júlio Aguiar

Portfólio em português e inglês com projetos de dados, BI, inteligência artificial e desenvolvimento.

Site: https://julioaguiar07.github.io/portfolio/

HTML, CSS e JavaScript, sem etapa de build. O GitHub Pages publica a branch `main`, na raiz.

- `index.html`: estrutura da página
- `app.js`: textos, projetos e interações
- `style.css`: estilos responsivos
- `assets/`: imagens, vídeo e currículos

As imagens e documentos pessoais pertencem ao titular do portfólio. O vídeo de fundo mantém os direitos de seu respectivo autor.
